# 你好，我是 Randall

[English](./README.md) · 中文

AI 生成的页面已经能在浏览器里运行了，我却还想把它带回设计工具，继续调整。这个断点让我做了一个网页转 Figma 的工作流，也让我继续追问：屏幕前后，还有哪些体验需要一起考虑？

我是一名产品设计师，通过可以运行的原型、小产品和可复用工具来探索想法。我借助 AI coding agent 把想法做出来，检查其中的设计决定，再找到值得继续修改的地方。

## 我持续关注的问题

- **真正的阻力在哪里？** 我想理解一个人原本要完成什么、前后有哪些步骤，以及其中哪一部分值得改变。
- **产品应该替人决定多少？** 我在探索默认方案、自动化和自主调整之间的关系，让人能参与结果的形成。
- **完整的体验怎样成立？** 我也在思考第一次使用、再次回来的理由、出错时的处理，以及让产品持续有用的维护成本。

这些问题引导着我的实验。下面的项目分别探索其中的一部分。

## 精选项目

### [Web to Hi-Fi Figma](https://github.com/RandallisLeo/web-to-figma-hi-fi)
**让生成之后的设计仍然可以编辑**

把已经实现的网页转成可编辑的 Figma 布局，保留文字、自动布局、组件，并进行视觉核对。它来自一个具体需求：把能运行的网页想法带回设计流程，继续推敲。

### [Bloom Studio](https://github.com/RandallisLeo/bloom-studio)
**让人参与生成结果的塑造**

一个结合图片分析、程序化几何与直接调节的花朵设计工作室，可以调整形状、颜色和绽放过程。我在探索：生成一个起点之后，怎样让用户继续塑造它。

### [UI/UX News Digest](https://github.com/RandallisLeo/uiux-news-digest)
**把分散的更新变成有用的设计信息**

核对原始来源，筛选一周的产品与界面更新，再整理成可视化简报。这个项目里的设计问题，是判断什么值得关注，并解释它为什么与设计工作有关。

### [Move Club](https://github.com/RandallisLeo/move-club-motion)
**通过制作，理解交互的感受**

一个持续增长、可以直接操作的交互与动效研究集合。我重做界面里的小瞬间，观察时序、连续性、反馈和空间关系怎样影响体验。

[体验在线作品](https://move-club-motion.vercel.app)

## 更多实验

- [GitHub Skill Radar](https://github.com/RandallisLeo/github-skill-radar) — 发现正在受到关注的 agent skills，并筛选出值得进一步研究的候选。
- [Hatch My Codex Pet](https://github.com/RandallisLeo/hatch-my-codex-pet) — 把角色设计拆成可见、可确认的选择，逐步形成动画角色的制作流程。

这个 GitHub 会慢慢记录我做过什么、为什么这样选择，以及我对设计和产品的理解如何随着制作而改变。
